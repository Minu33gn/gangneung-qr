# 강릉시청자 SNS 안내 페이지

QR을 스캔한 방문자가 강릉시청자 인스타그램, 유튜브, 페이스북과 강릉시청 공식 홈페이지로 이동하는 모바일용 정적 페이지입니다.

## 배포와 QR 주소

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포합니다.

배포용 주소: https://minu33gn.github.io/gangneung-qr/

최초 배포 완료 후 위 주소를 네이버 QR 코드에 입력합니다. 이후 QR을 유지하려면 GitHub 계정명과 저장소명(`gangneung-qr`)을 유지하고 페이지 파일만 수정합니다. Codex 대화나 작업 폴더 이름은 배포 주소와 무관합니다.

## 수정

- `config.js`: 채널 주소와 문구
- `index.html`: 제목과 화면 구성. 주소 수정 시 `noscript` 링크도 수정합니다.
- `style.css`: 디자인
- `assets/haslang.png`: 하슬랑 이미지
- `assets/gangneung-logo.png`: 강릉시 로고

캐릭터는 사용자 첨부 시안에서 배경을 분리한 이미지입니다. 공식 투명 원본을 확보하면 같은 파일명으로 교체할 수 있습니다.

저장된 코드 작업 지침에 따라 별도 테스트와 브라우저 확인은 수행하지 않았습니다.
