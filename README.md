# 강릉시청자 SNS 안내 페이지

QR을 스캔한 방문자가 강릉시청자 인스타그램, 유튜브, 페이스북과 강릉시청 공식 홈페이지로 이동하는 모바일용 정적 페이지입니다.

## 배포와 QR 주소

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포합니다.

배포용 주소: https://minu33gn.github.io/gangneung-qr/

이 주소를 QR 코드에 입력합니다. GitHub 계정명과 저장소명(`gangneung-qr`)을 유지하고 페이지 파일만 수정하면 기존 QR도 같은 페이지로 연결됩니다.

## 이미지와 클릭 영역

사용자가 제공한 `4306.jpg`를 `assets/gangneung-social-poster.jpg`로 그대로 표시합니다. 원본 크기는 787 × 1280입니다.

이미지 위에 실제 HTML 링크 네 개를 배치합니다. 이미지의 표시 크기에 맞춰 클릭 영역도 함께 확대·축소됩니다. 링크는 같은 탭에서 열리고 JavaScript 없이도 사용할 수 있으며, 키보드와 화면 읽기 프로그램으로도 선택할 수 있습니다.

## 수정

- `assets/gangneung-social-poster.jpg`: 화면에 표시하는 이미지
- `style.css`: 이미지 크기와 버튼 클릭 영역. 다른 구도의 이미지로 교체할 때 버튼 좌표도 조정합니다.
- `config.js`: 채널 주소와 안내 문구. JavaScript가 꺼진 경우를 위해 `index.html`의 링크도 같은 주소로 수정합니다.
- `index.html`: 페이지 설명, 이미지, 기본 링크와 접근성 문구
- `script.js`: 설정 파일의 주소와 문구를 기본 링크에 적용

CSS 클릭 영역은 원본 이미지의 좌표를 백분율로 환산한 값입니다. 버튼은 x=53부터 x=734까지, 높이 136이며 시작 y좌표는 인스타그램 575, 유튜브 725, 페이스북 876, 홈페이지 1025입니다.
